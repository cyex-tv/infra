# Rules for Claude Code

This repo is part of cyex.tv. The rules in [cyex-tv/platform CLAUDE.md](https://github.com/cyex-tv/platform/blob/main/CLAUDE.md) apply here in full: the plan is `PLAN.md` there, the separation from cyex.app, the GitHub scope, and the borrowed-code rules.

In short:
- One task = one branch = one PR. Never push to `main`; the owner merges.
- Commit author: `claude`.
- No secrets in this repo; it is public (AGPL-3.0).
- Never change anything belonging to cyex.app or cyex-api.
