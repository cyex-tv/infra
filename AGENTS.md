# Rules for coding agents

This repo is part of cyex.tv. The rules in [cyex-tv/platform AGENTS.md](https://github.com/cyex-tv/platform/blob/main/AGENTS.md) apply here in full: the plan is `PLAN.md` there, the separation from cyex.app, the GitHub scope, and the borrowed-code rules.

In short:
- One task = one branch = one PR. Never push to `main`; the owner merges.
- Commits are authored by the owner's GitHub account. No co-author trailers, and no tool or AI attribution anywhere.
- No secrets in this repo; it is public (AGPL-3.0).
- Never change anything belonging to cyex.app or cyex-api.
